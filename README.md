# 🍽️ ShareMeal

## Connecting People Through Food Donations

**ShareMeal** is a web application designed to connect food donors with people or organizations that need food. The platform aims to reduce food waste and make food donation easier and more accessible.

## 🌐 Live Demo

Visit the live application:

**https://meals-sand-seven.vercel.app/**

---

## ✨ Features

* 🍲 Donate available food
* 📋 View available food donations
* 🔐 User authentication
* 🔥 Firebase integration for data storage
* 📱 Responsive user interface
* ⏰ Food availability and expiration management
* 🤝 Connect donors with people in need

## 🚀 Run Locally

### Prerequisites

Make sure you have **Node.js** installed on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/Nagendra-avg-art/meals.git
```

### 2. Navigate to the project

```bash
cd meals
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on a local development URL displayed in your terminal.

## 🔥 Firebase Setup

This project uses Firebase for authentication and data management.

Create a Firebase project and configure your Firebase credentials in the appropriate configuration file.

> ⚠️ Never upload private API keys, passwords, or secret credentials to GitHub.

Use environment variables for sensitive information.

Example:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
```

## 🎯 Problem Statement

Large amounts of food are wasted every day while many people struggle to access sufficient food.

**ShareMeal aims to solve this problem by creating a platform where:**

1. Food donors can post available food.
2. People or organizations can view available donations.
3. Food can be shared before it expires.
4. Food waste can be reduced.
